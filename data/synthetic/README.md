# Synthetic datasets

Synthetic CRM, Operations and Google Sheets-style files (174 records, 2024-11 to 2026-10). No real company, customer or prospect data is permitted here.

```
crm/            crm_companies.csv, crm_leads.csv
operations/     ops_projects.csv
google-sheets/  sales_targets_forecasts.csv, campaign_mapping.csv, account_segments.csv
mappings/       client_mapping.csv
defect_manifest.json   intentional test defects (used by the validator)
```

Field definitions: `docs/DATA_DICTIONARY.md`. Do not edit by hand; see `scripts/`.
